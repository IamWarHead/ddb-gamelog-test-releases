# DDB Gamelog – test builds

Alpha and beta builds of DDB Gamelog v3 for Foundry VTT.
During the open beta (November 9–15, 2026) anyone can connect, no Patreon needed;
join the test from inside Foundry for 3 days of Gamelog PRO.

**Tester documentation:** https://iamwarhead.github.io/ddb-gamelog-test-releases/
Install, first steps, features, tiers, troubleshooting and the changelog.

**Not a tester?** Install the stable module from Foundry's module browser or
https://github.com/IamWarHead/ddb-game-log.

**Testers:** install via *Add-on Modules → Install Module → Manifest URL* with

```text
https://github.com/IamWarHead/ddb-gamelog-test-releases/releases/download/test-channel/module.json
```

It always points at the newest test build. Feedback: https://discord.com/invite/HSTtrphyFg
