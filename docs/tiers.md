# Tiers

Gamelog features depend on your Patreon membership.

{: .warning }
This is a test build. Tiers and what belongs to them may change before release. Please report problems, see [Feedback]({% link feedback.md %}).

| Tier | Price |
| --- | --- |
| Free | $0 |
| Gamelog Basic | $3 |
| Gamelog PRO | $5 |
| Gamelog MAX | $15 |

Each tier includes everything in the tiers below it. Gamelog MAX has the same features as Gamelog PRO; what you get on top of them is priority support, Discord roles and early access to test builds.

## Features by tier

| Feature | Tier |
| --- | --- |
| Rolls from the D&D Beyond website in Foundry chat | Free |
| Pending ("rolling…") cards, roll result breakdown | Free |
| D&D Beyond roll targets respected (to DM / self stay private) | Free |
| Manual character linking, initiative tracking | Free |
| Clicking a card selects and pans to the token | Free |
| Card themes, player colours | Basic |
| D&D Beyond character avatars on cards | Basic |
| Clicking a card opens the sheet or D&D Beyond | Basic |
| Automatic linking of ddb-importer characters | Basic |
| Item and spell links on cards | PRO |
| Monster rolls | PRO |
| Rolls from the D&D Beyond mobile app | PRO |
| Live character and condition updates | PRO |
| Apply damage and healing from cards | PRO |
| Dice So Nice, JB2A + Automated Animations | PRO |
| Discord relay of public rolls | PRO |
| Midi-QoL integration (experimental) | PRO |
| D&D Beyond combat tracker in Foundry (experimental) | PRO |
| Priority support, Discord roles, early access | MAX |

## Get a membership

Join on [Patreon](https://www.patreon.com/iamwarhead/).

Then link Patreon to your world on the Connection page, see [First steps]({% link first-steps.md %}#link-patreon). Changes on Patreon apply within seconds.

## During the test

When you join the test, the Connection page shows your tier and how many days you have left.

- Closed alpha: you get the Gamelog MAX features for 7 days.
- Closed beta: you get your own tier, and at least the PRO features, for 7 days.
- Open beta: you get the Gamelog PRO features for 3 days, even without a Patreon tier.

Dates and who can join are on the [Home]({% link index.md %}#current-test-phase) page.
